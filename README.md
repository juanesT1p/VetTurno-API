# VetTurno

API REST para la Veterinaria Huellitas, construida con Java 17 y Spring Boot.

La configuración local se guarda en `application-local.properties`, archivo que no se versiona. Usa `application-local.properties.example` como guía para crearla.

## Estado

Proyecto base en construcción. La documentación de endpoints y seguridad se completará al finalizar la implementación.
